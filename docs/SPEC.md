# 彩盒签样复检数据与算法

导入自备批次或复核估计时阅读。先核对下面的字段和时间窗。查看隔离行原因，再核对估计和派发结果。

## 单据

| 字段 | 用途 | 单位 | 有效区间 |
|---|---|---|---|
| `cyan_shift` | 青版密度偏差 | 0.01D | -24–43 |
| `magenta_shift` | 品红密度偏差 | 0.01D | -30–48 |
| `register_um` | 套准偏差 | μm | 8–128 |
| `moisture` | 纸张含水率 | 0.1% | 40–95 |
| `ink_c` | 油墨温度 | ℃ | 16–43 |
| `image_blocks` | 版面高密度块 | 块 | 1–32 |

`key` 是单号，`cohort` 是作业区，文本先做 NFKC 归一化。`day` 为测量工日，`received` 为到站工日，`revision` 为正整数版次。同版记录出现多个不同测量结果时隔离该单全部版次。缺测可空置，但每条单至少包含四项观测。

`outcome` 与 `result_day` 成对填写。标签 0 为已核实正常，1 为需要复核的实绩。 `observed` 省略时为 `true`，只在留架右截尾场景允许 `false`。

### 原始行业单据

允许使用 `form` 对象代替平铺量测。保留单号、版次、工日和标签等顶层字段。表中的换算为 `(单据值 − 原点偏移) / 倍率`。每行内部校验完成后，与平铺数据使用同一分窗、建模和派单过程。

| 单据组 | 原始字段 | 用途 | 倍率 | 原点偏移 |
|---|---|---|---:|---:|
| 机台密度 | `cyan_milli_od` | 青色千分密度 | 10 | 0 |
| 机台密度 | `magenta_milli_od` | 品红千分密度 | 10 | 0 |
| 套准读数 | `plate_nm` | 样张错位纳米 | 1000 | 0 |
| 套准读数 | `paper_basis_points` | 纸张含水万分数 | 10 | 0 |
| 纸张墨路 | `ink_deci_c` | 墨温十分度 | 10 | 0 |
| 纸张墨路 | `image_work_blocks` | 图像密集块 | 1 | 0 |

示例见 `sample_data/print_tickets_form.json`。混合使用两种量测表示，或单据内读数互相矛盾时，保留隔离原因。

## 时序与训练

拟合 `[0,40)`、校准 `[42,62)`、回放 `[65,83)`、当班从 `88` 日起。前三个窗口的入站和结果都须早于窗口终点。到站日晚于截止日的单据在入站隔离。拟合期冻结补值中位数、均值、尺度及训练包络。

| 特征 | 语义 | 公式 |
|---|---|---|
| `color_radius` | 双色偏差模长 | `(cyan_shift**2+magenta_shift**2)**.5` |
| `registration` | 密版套准漂移 | `register_um*(1+image_blocks/40)` |
| `paper_jump` | 纸张水分偏离 | `abs(moisture-62)` |
| `ink_exposure` | 油墨与版面交互 | `max(0,ink_c-26)*image_blocks/10` |
| `pigment_gap` | 通道相对色偏 | `cyan_shift-magenta_shift` |

### 高斯朴素贝叶斯签样

利用全体样本方差作为类内先验，对低频类别平滑。归一化后验时先减去两个联合对数分数的最大值。

本工作台的独立样本校准方式为签样置信温度。风险校准无法确认正负样本时转人工判读。连续估计使用独立校准残差计算双侧区间，误差尺度随作业条件变化。分布监测对训练和当班量测比较分位位移。未知作业区、两项缺测或两项明显超训练包络的单据需要人工判读。

## 派发签样复检

| 优先级 | 原因码 | 条件 | 处置依据 |
|---:|---|---|---|
| 1 | `REGISTRATION_HOLD` | `register_um >= 105 and image_blocks >= 17` | 先暂停签样并重新套准 |
| 2 | `WET_STOCK` | `moisture >= 84 and ink_c >= 29` | 湿纸热墨需复测 |
| 3 | `DUAL_DRIFT` | `cyan_shift >= 26 and magenta_shift >= 28` | 双色同时正偏 |

第一条为暂停规则。其余命中与模型阈值 `0.51` 共同决定是否列入候选。单据所需工位数按 `1 + int(image_blocks >= 14)` 计算。均衡策略对分区限额，集中复核策略允许把额度集中投入高风险区。未分派原因在导出的处置记录中保留。签发前核对每张当班单和工位余额。

### 只缺青版密度的色样票

当 `missing == ('cyan_shift',)` 时，取同作业区在成熟拟合窗内的青版实测最小值和最大值；到站或结果晚于拟合终点的样本已在分窗阶段隔离，不参与该范围。分别代入两个边界，复用本次冻结的特征状态、模型和温度校准复算预测：

- 同区没有青版实测：`CYAN_COHORT_REFERENCE_MISSING`，转人工判读，不占用工位。
- 两个复算预测的下界仍不低于 `0.51`：视为区间内始终达线，按正常候选和工位余额派单。
- 两个复算预测的上界仍低于 `0.51`：视为始终线下，保留观察。
- 其余情况为预测区间跨过复检线：`CYAN_RANGE_CROSSES_LINE`，转人工判读，不占用工位。

套准、湿纸热墨等已实测规则，以及 `OUT_OF_REFERENCE`、校准不足等已有判读优先于青版缺测区间。单据详情的“青版缺测复算依据”和处置证据保留同区上下限、端点预测与判定；同批输入换序必须得到相同处置、原因和工位占用。

### 色块复检安排

青色和品红的读数先按纸张含水率及墨温折算。至少三张相同纸况的常态签样才提供组内对照。套准、供墨和单版网点使用不同色块复检。 在派发环节展开现场安排，或从关联单据回查实际读数。
